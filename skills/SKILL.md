## マルチエージェント・並列開発におけるトラブルシューティング

### Screenセッションが予期せず終了した、または見つからない

**症状**:
`./scripts/manage-screen.sh status` を呼び出した際、`Screen session not running` と出力され、セッションステータスが更新できない。

**原因**:
エージェントプロセスで致命的なエラーが発生して `agy` が異常終了した、または `screen` プロセスがクラッシュした。

**対処**:

1. **ログの確認**:
   - `screen -ls` で現在生きているセッションがあるか確認する。
   - `docs/tasks/{agent-ID}-{通し番号}-{タスク名}.md` の中に書き込まれた `pid` と一致するログがあるか探す。
2. **再起動**:
   - 途中から処理を再開する場合、同じタスク名を指定して再度スタートさせる。
     ```bash
     ./scripts/manage-screen.sh start <タスク名>
     ```
     ※ これにより新しい screen セッションが立ち上がり、タスクファイルの `pid` が新しいものに自動上書きされます。

### Git Subtree のマージ時にコンフリクトが発生する

**症状**:
`/pr-create` 実行時に `git subtree` ブランチの統合マージがコンフリクトで失敗する。

**原因**:
別々のエージェントが、それぞれに割り当てられた subtree ディレクトリ（プレフィックス）の外側にある共通コード（`settings.json` や共用のユーティリティなど）を同時に変更してしまった。

**対処**:

1. **手動でのコンフリクト解消**:
   - 該当するファイルを手動で開き、競合箇所をマージツール等で解消する。
2. **subtree 境界の再確認**:
   - 変更されたファイルが本当にそのエージェントの担当範囲内かを確認する。もし境界外のファイルを誤って編集していた場合は、元のブランチから対象ファイルをリセットし、必要な共通処理は事前タスク（直列タスク）に切り出すように計画を調整する。
