# 未完了タスクの一括並列起動

あなたは全体の進行役（オーケストレーター）として動作し、マルチエージェントの実装を一括で開始します。
仕様の追加や変更による「追加開発フェーズ」においても、未完了のタスクのみを判別して起動します。

## 実行手順

1. **全体調整計画書の確認**:
   - `docs/tasks/orchestration-plan.md` を読み込み、実行スケジュールに定義されている個別タスク指示書ファイルの一覧を取得する。

2. **未完了タスクの抽出（完了済みタスクのスキップ）**:
   - 各個別タスクファイルの YAML フロントマターを確認する。
   - すでに `status: done` になっているタスクは、実装が完了しているため**起動をスキップ**する。
   - `status` が `planning` / `doing` / `reviewing` / `fixing` である、または新しく追加されて `status: done` 以外になっているタスクのみを起動対象として抽出する。

3. **エージェントセッションの起動**:
   - 抽出した未完了タスクそれぞれについて、管理シェルスクリプトを実行して Screen セッションをバックグラウンドで起動する。
     ```bash
     ./scripts/manage-screen.sh start <個別タスク名>
     ```

4. **起動完了の報告とユーザーへの案内**:
   - 今回新しく起動したタスクの一覧と、それぞれの `screen` の PID を報告する。
   - スキップされた完了済みタスクの一覧も明示する。
